2. ESQUEMA DE OBJETIVOS ADOPTADO

El esquema JSON 1.1 conserva bio_objectives y agrega la lista ordenada
objectives. No se permiten ambos campos en el mismo documento. Biobjetivo
admite objectives con exactamente 2 elementos. Multiobjetivo exige al menos 3.
El orden define Z1, Z2, ..., Zp y name es descriptivo/opcional. Todo se
normaliza internamente a una lista ordenada de objetivos lineales.

El esquema JSON 1.0 no cambió y sus dos objetivos históricos también se
exponen internamente como lista para el nuevo builder general.

INTERPRETACIÓN

El runner conserva la ruta biobjetivo existente y usa un motor general
separado solo cuando hay tres o más objetivos. Los rangos epsilon son extremos
observados en la matriz de pagos, no un nadir exacto. Las proyecciones 2D son
vistas parciales del conjunto obtenido, con dominancia calculada en N
dimensiones.

CONCLUSIÓN

Las observaciones demuestran que el modo normal es guiado y no bloquea CI, el
producto cartesiano de niveles y los r individuales funcionan, la dominancia
considera todos los objetivos y las regresiones biobjetivo permanecen intactas.
