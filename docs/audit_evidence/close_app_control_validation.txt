     expander discreto "Sesion" y separado de "Nuevo" y "Resolver".

     _init_session_state(), antes de renderizar barra lateral, formulacion,
     restricciones, solver, resultados, modelo indexado o graficos.
   - La pantalla muestra "⏻ Aplicacion cerrada", aclara que el servidor local
     continua activo, ofrece "Reabrir aplicacion" y finaliza el render con
     st.stop().

   - La ruta de formulacion usa persist_state="session" para conservar tambien
     la seleccion visual durante el cierre temporal.
   - No se usa os._exit, sys.exit, subprocess, taskkill, kill, APIs privadas de
     Streamlit, JavaScript window.close ni apagado forzado del servidor.

INTERPRETACION
--------------

El estado app_closed afecta exclusivamente al render de la sesion actual. La
salida temprana evita ejecutar la interfaz principal mientras esta cerrada y no
altera el modelo. El servidor y las demas sesiones permanecen activos.

CONCLUSION
----------

El control implementado satisface el cierre seguro por sesion, conserva el
trabajo explicito e indexado y permite reabrir la interfaz sin terminacion del
proceso Streamlit. Todas las regresiones matematicas y de UI pasaron.
